帮助研究者识别单看价格容易遗漏的风险。

01

先看结构

用波动率溢价与隐含相关性，观察个股与指数之间的分化。

02

再查拥挤

结合 Call/Put、左尾 Skew 与情绪，检查方向交易和下行保护。

03

回到价位

对照 SPX 与 HVL 参考值。0—1 项为常规观察，2—3 项进入观察，4—6 项标记结构脆弱；这是规则计数，尚非经回测校准的概率模型。

数据口径与使用说明 DATA & METHODOLOGY ＋

当前 GitHub Pages 使用仓库中的手动快照。采集时间不等于各指标的市场观测时间；展开来源可查看原始口径。重新读取只会加载最新文件，不会生成实时行情。

Call/Put 与 Skew 使用快照注明的标的和样本，不能外推为整个半导体行业。静态快照用于研究展示，不是实时预警服务。
